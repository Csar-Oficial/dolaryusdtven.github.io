¿Cómo instalar como App / APK?

Método 1: Instalar directo (Sin compilar)

Esta app ya cuenta con arquitectura PWA. Si la abres desde Chrome en Android:

  1. Toca los tres puntos de Chrome (⋮).
  2. Selecciona "Agregar a la pantalla principal" o "Instalar aplicación".
  3. Se creará el ícono en tu móvil y funcionará como una app nativa sin barra de navegador.

Método 2: Generar archivo binario .APK

Para compilar este código en un instalador .apk listo para compartir por WhatsApp o Drive:

Opción A: Web2Apk / Website2APK Descarga este archivo HTML, súbelo a herramientas online como gonative.io o appsgeyser.com y descarga el archivo .apk directo.
Opción B: Capacitor / Cordova Empaqueta este index.html con npx cap add android y genera el APK en Android Studio en 2 minutos.
